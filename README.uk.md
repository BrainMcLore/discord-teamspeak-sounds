# Звуки TeamSpeak для Discord

[Русский](README.md) | [English](README.en.md) | **Українська**

Скрипт для Windows, який замінює звуки мікрофона та голосових каналів Discord на класичні звуки TeamSpeak 3. Застосовується вручну й може бути запущений повторно після оновлення Discord.

Vencord, BetterDiscord та окрема фонова програма не потрібні. Невеликий патч завантажується в наявний процес Discord.

## Встановлення

1. Натисніть **Code → Download ZIP** і розпакуйте весь архів.
2. Повністю закрийте Discord через його значок біля годинника: **Quit Discord**.
3. Запустіть `Apply.cmd` подвійним клацанням.
4. Відкрийте Discord звичайним способом.

Після оновлення Discord повторіть кроки 2–4. Зберігайте CMD-файли разом з іншими файлами та папкою `sounds`.

## Відновлення та перевірка

- **`Restore.cmd`** повертає початковий завантажувач. Спочатку повністю закрийте Discord, виконайте відновлення, а потім знову відкрийте програму.
- **`Status.cmd`** показує, чи встановлено патч, та останні записи його журналу.

`TS-SOUNDS-HIT:mute`, `unmute`, `user_join`, `user_leave` або `disconnect` означає, що запит звуку було перехоплено й замінено. Запис `ready` підтверджує завантаження обробника, але сам по собі не підтверджує відтворення.

## Звуки

| Подія Discord | Початковий файл TeamSpeak 3 |
| --- | --- |
| Вимкнення мікрофона | `mic_muted.wav` |
| Увімкнення мікрофона | `mic_activated.wav` |
| Підключення / приєднання учасника | `neutral_switched_tocurrentchannel.wav` |
| Вихід учасника | `neutral_switched_awayfromcurrentchannel.wav` |
| Власне відключення | `disconnected.wav` |

Discord використовує один звук для власного підключення та приєднання іншого учасника. Підтримуються звичайні, Halloween і зимові варіанти ресурсів — загалом 15 адрес. Відповідні звуки мають бути ввімкнені в налаштуваннях сповіщень Discord.

## Як це працює

`Manage-Sounds.ps1` знаходить останню встановлену версію Discord у стандартній папці користувача або в `%ProgramData%\%USERNAME%\Discord`. Перед зміною `index.js` створюється резервна копія `index.js.ts-original`. Повторне застосування зберігає цю початкову копію. Скрипт відмовляється перезаписувати невідомий завантажувач.

Під час застосування публічна сторінка Discord та її `web.*.js` використовуються для оновлення назв аудіофайлів. Якщо їх не вдалося отримати, використовується вбудований список. Авторизація для цього завантаження не потрібна.

Під час запуску Discord патч замінює запити до зазначених аудіоресурсів локальними WAV-файлами. Інші запити передаються штатному обробнику. Скрипт не звертається до токенів і паролів.

CMD-файли дозволяють виконання PowerShell-скрипта лише в запущеному процесі; постійна політика Windows не змінюється. Права адміністратора зазвичай не потрібні. Відновлення вимикає патч, залишаючи резервну копію та неактивні файли поруч із завантажувачем.

## Сумісність і перевірка

Перевірено на Discord **1.0.9265**, Windows, 28 жовтня 2026 року:

- запуск клієнта з патчем;
- перехоплення реальних запитів mute, unmute, user_join і user_leave;
- повторне застосування та відновлення завантажувача;
- точний збіг байтів WAV для всіх 15 адрес;
- заміна `media.src` і `play`, передавання сторонніх запитів без змін;
- синтаксис JavaScript і PowerShell, структура п’яти WAV-файлів.

Окремо не підтверджено реальну подію `disconnect` і чутне відтворення на конкретному пристрої виведення. Зміни механізму відтворення в майбутніх версіях Discord можуть вимагати оновлення самого патча, а не лише повторного запуску `Apply.cmd`.
