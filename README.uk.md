Скрипт для Windows, який замінює звуки мікрофона та голосових каналів Discord на класичні звуки TeamSpeak 3. Застосовується вручну й може бути запущений повторно після оновлення Discord.

Vencord, BetterDiscord та окрема фонова програма не потрібні. Невеликий патч завантажується в наявний процес Discord.

## 🎧 Лаунчер

**v3.0 SoundSpace:** новий інтерфейс із картками та власна іконка. Спільний хмарний воркшоп уже підключено: користувачі публікують паки прямо з програми, а інші можуть шукати їх за назвою чи автором, вибирати категорії, слухати й завантажувати.

Вхід через GitHub або email і пароль. Для email спочатку підтвердьте адресу листом Firebase. Вхід і реєстрація мають окремі екрани; доступні скидання пароля та повторне підтвердження. Для попередніх акаунтів залишено вхід за старим логіном.

У розділі **«Мої публікації»** можна видалити власний пак після підтвердження. Сервер перевіряє власника. Хмарні ліміти: 8 МБ на пак, 64 МБ на акаунт, 512 МБ для спільного тестового каталогу. Адресу сервера вже налаштовано; окремий акаунт Cloudflare користувачам не потрібний.

Завантажте **[SoundSpace Setup.exe](https://github.com/BrainMcLore/discord-teamspeak-sounds/releases/latest/download/SoundSpace-Setup-v3.0.1.exe)** і відкрийте його. Майстер запропонує папку встановлення та створення ярлика на робочому столі. Потрібна Windows із .NET Framework 4.8.

- Пресети **TeamSpeak Female**, **TeamSpeak Male** та **Classic Clicks**.
- Власні WAV/MP3 для кожної із семи подій, прослуховування до застосування.
- Зніміть позначку, щоб залишити оригінальний звук Discord для події.
- Імпорт та експорт паків `.dspack`, збереження вибору між запусками.
- Воркшоп: спільний каталог користувачів, публікація з програми та завантаження з перевіркою SHA256.
- Інтерфейс російською, англійською та українською.

Завантажити й відкрити лаунчер однією командою PowerShell:

```powershell
& ([scriptblock]::Create((irm 'https://raw.githubusercontent.com/BrainMcLore/discord-teamspeak-sounds/main/Install.ps1?setup=4')))
```

Лаунчер можна відкрити одночасно з Discord. Перед застосуванням або відновленням повністю закрийте Discord, а потім запустіть знову. Лаунчер можна закрити — для відтворення звуків він не потрібен.

Паки містять лише метадані та аудіо, до 10 МБ на локальний звук. Для хмарної публікації архів має бути не більший за 8 МБ. Спільний воркшоп працює через Cloudflare.

Для збирання з вихідного коду запустіть `Build-Launcher.ps1` або `Launcher.cmd`. Готовий реліз уже містить EXE. Налаштування та локальна бібліотека зберігаються в `%LOCALAPPDATA%\DiscordTeamSpeakSounds\launcher`.

## 🚀 Встановлення

### Через PowerShell

```powershell
& ([scriptblock]::Create((irm 'https://raw.githubusercontent.com/BrainMcLore/discord-teamspeak-sounds/main/Install.ps1?setup=4')))
```

Команда завантажує останній EXE, перевіряє SHA256 і відкриває майстер встановлення. Виберіть папку та за бажанням увімкніть ярлик на робочому столі. Повністю закрийте Discord перед застосуванням звуків; для встановлення лаунчера це не потрібно.

### Переносна версія

[ZIP без встановлення — v3.0.0](https://github.com/BrainMcLore/discord-teamspeak-sounds/releases/tag/v3.0.0): розпакуйте повністю та відкрийте `Discord-Sound-Launcher.exe`. Для цього режиму додайте до PowerShell-команди `-Portable`. Використовуйте `-Apply` для застосування класичних звуків без лаунчера, попередньо повністю закривши Discord.

## ↩️ Відновлення та перевірка

- **`Restore.cmd`** повертає початковий завантажувач. Спочатку повністю закрийте Discord, виконайте відновлення, а потім знову відкрийте програму.
- **`Status.cmd`** показує, чи встановлено патч, та останні записи його журналу.

`TS-SOUNDS-HIT:mute`, `unmute`, `user_join`, `user_leave` або `disconnect` означає, що запит звуку було перехоплено й замінено. Запис `ready` підтверджує завантаження обробника, але сам по собі не підтверджує відтворення.

## 🔊 Звуки

| Подія Discord | Початковий файл TeamSpeak 3 |
| --- | --- |
| Вимкнення мікрофона | `mic_muted.wav` |
| Увімкнення мікрофона | `mic_activated.wav` |
| Вимкнення звуку кнопкою навушників | `sound_muted.wav` — Sound muted |
| Увімкнення звуку кнопкою навушників | `sound_resumed.wav` — Sound resumed |
| Підключення / приєднання учасника | `neutral_switched_tocurrentchannel.wav` |
| Вихід учасника | `neutral_switched_awayfromcurrentchannel.wav` |
| Власне відключення | `disconnected.wav` |

Discord використовує один звук для власного підключення та приєднання іншого учасника. Підтримуються звичайні, Halloween і зимові варіанти ресурсів — загалом 21 адреса. Відповідні звуки мають бути ввімкнені в налаштуваннях сповіщень Discord.

## ⚙️ Як це працює

`Manage-Sounds.ps1` знаходить останню встановлену версію Discord у стандартній папці користувача або в `%ProgramData%\%USERNAME%\Discord`. Перед зміною `index.js` створюється резервна копія `index.js.ts-original`. Повторне застосування зберігає цю початкову копію. Скрипт відмовляється перезаписувати невідомий завантажувач.

Під час застосування публічна сторінка Discord та її `web.*.js` використовуються для оновлення назв аудіофайлів. Якщо їх не вдалося отримати, використовується вбудований список. Авторизація для цього завантаження не потрібна.

Під час запуску Discord патч замінює запити до зазначених аудіоресурсів локальними WAV-файлами. Інші запити передаються штатному обробнику. Скрипт не звертається до токенів і паролів.

CMD-файли дозволяють виконання PowerShell-скрипта лише в запущеному процесі; постійна політика Windows не змінюється. Права адміністратора зазвичай не потрібні. Відновлення вимикає патч, залишаючи резервну копію та неактивні файли поруч із завантажувачем.

## ✅ Сумісність і перевірка

Для кнопки навушників перевірено підстановку точних WAV та обробку звичайних і сезонних адрес. Перевірка обробника охоплює всі 21 адресу. Реальне натискання кнопки з новою версією окремо не перевірялося.

Перевірено на Discord **1.0.9265**, Windows, 28 жовтня 2026 року:

- запуск клієнта з патчем;
- перехоплення реальних запитів mute, unmute, user_join і user_leave;
- повторне застосування та відновлення завантажувача;
- точний збіг байтів WAV для всіх 15 адрес;
- заміна `media.src` і `play`, передавання сторонніх запитів без змін;
- синтаксис JavaScript і PowerShell, структура п’яти WAV-файлів.

Окремо не підтверджено реальну подію `disconnect` і чутне відтворення на конкретному пристрої виведення. Зміни механізму відтворення в майбутніх версіях Discord можуть вимагати оновлення самого патча, а не лише повторного запуску `Apply.cmd`.
