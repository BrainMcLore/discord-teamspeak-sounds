# Changelog

## 3.0.0 — 2026-10-28

- Rebuilt the launcher with WPF: dark cards, orange accents, waveform artwork and original SoundSpace icon.
- Live shared Cloudflare workshop: real user publications, title/author search, categories and newest/popular sorting.
- GitHub device sign-in with verified email and replay-protected authorization flows.
- Firebase email/password sign-in with verification email, resend and password reset.
- Separate sign-in and registration screens; registration confirms the password.
- My uploads with confirmation and server-side ownership checks for deletion.
- Legacy username sign-in preserves access to existing accounts and publications.
- Localized account validation and readable server errors.

## 2.0.0 — 2026-10-28

- Windows launcher with Russian, English, and Ukrainian interface.
- Custom WAV/MP3 sounds, event selection, preview, saved settings.
- TeamSpeak Female, TeamSpeak Male, and Classic Clicks presets.
- Import/export audio-only `.dspack` packs.
- GitHub workshop catalog with verified pack downloads and contributor instructions.
- Selective sound manifest, MP3 MIME support, original Discord sounds for unchecked events.
- One-command launcher download with `Install.ps1 -Launcher`.
- Checks for pack round trips, invalid archives, selective audio routing, patch/reapply/restore in an isolated Discord fixture.

## 1.2.0 — 2026-10-28

- One-command PowerShell installer: latest release download, SHA256 check, and patch application.

## 1.1.0 — 2026-10-28

- Sound muted / Sound resumed for the headphones button.
- Seven sound events and 21 standard/seasonal audio addresses.
- English and Ukrainian documentation alongside Russian.

## 1.0.0 — 2026-10-28

- Original TeamSpeak microphone, channel join/leave, and disconnect sounds.
- Repeatable application, loader backup, restoration, and status scripts.
